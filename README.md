# Iram's Memory Box

Build a premium, highly interactive digital birthday surprise website for Iram, created and gifted by her sister.

This website is a personal birthday gift from one sister to another.

The entire experience, wording, visual storytelling and emotional tone must be written from the sister's point of view.

IMPORTANT:

This is NOT a romantic website.

Do NOT use:

“My Love”

“To my love”

“Soulmate”

Romantic partner language

Valentine's-style design

Romantic relationship references

The relationship is:

Sister → Sister

The emotional tone should be:

loving as sisters

playful

warm

nostalgic

appreciative

emotional

slightly fun

personal

birthday-focused

It should feel like:

“I made this little digital world for my sister because I wanted her birthday to feel extra special.”

==================================================
CORE CONCEPT

Do NOT create a conventional website with:

Home → Gallery → Letter → Gifts.

Instead create an interactive DIGITAL BIRTHDAY GIFT BOX.

The experience should be:

Iram opens the website.

She sees a beautiful birthday gift box.

She opens the box.

Inside are several carefully prepared surprises.

She discovers:

📖 A MEMORY ALBUM
💌 A BIRTHDAY LETTER FROM HER SISTER
🌸 A FLOWER BOUQUET
🎁 HER BIRTHDAY GIFTS

Each object is interactive.

The website should feel like she is physically opening a birthday present from her sister.
